-----------------------------------
1. ТАБЛИЦА USERS
-----------------------------------

Создать таблицу users:

create table if not exists users (
  id uuid primary key,
  email text,
  role text,
  approved boolean default false,
  created_at timestamp default now()
);

Важно:
- id = auth.uid()
- связь с Supabase Auth

  approved = false
